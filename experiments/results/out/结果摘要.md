# 参数筛选有效性检验 · 结果摘要

> 状态：**预实验结果**（1 个工况、1 组冻结种子，另有 1 次换种子复核）。
> 尚未做：文献范围依据核定、2³ 交互诊断、多工况迁移性检验（H2）。

## 一句话结论

在固定工况下，**只保留单因素敏感度排名前 3 的参数**（其余恢复基准），对"12 个候选参数同时变化"的稳态甲烷日产率的还原误差，比**同数量随机对照组**低 **61.6%**（29 组配对，bootstrap 95%CI [+15.3, +34.0] 不含 0），判定**筛选有效**。

## 实验口径

| 项 | 取值 |
| --- | --- |
| 基准 | PyADM1ODE 0.6.2，ADM1da 41 状态，单消化器 |
| 原料 | 玉米青贮 11.4 + 猪粪 6.1 + 牛粪 5.0 m³/d |
| 反应器 | V_liq 1050 m³，V_gas 150 m³，T 42 ℃，k_L_a 200 d⁻¹ |
| 主指标 | 稳态甲烷产率 = 150 天末段 24 h 的 Q_ch4 平均（m³ CH4/d） |
| 稳态判据 | 末段首末变化 < 1%/d（基准 1057.83 m³/d，满足） |
| 求解 | scipy · BDF，dt = 1 d |
| 随机种子 | **20261117**（冻结；复核用 20261118） |
| 总机时 | 115 次仿真 / 92.5 s（约 0.8 s/次） |

## 配对检验

- 拉丁超立方抽 **30 组**新组合（未参与排序）
- 每组三种设置：`S_all`（12 个全变，参照）、`S_top`（仅优先组，其余基准）、`S_ctrl`（等数量随机对照，其余基准）
- 对照组从非优先参数中抽取，逐组轮换

| 指标 | 值 |
| --- | --- |
| 有效组合 | **29 / 30 = 97%**（1 组未通过稳态判据，单列不计，未填零） |
| MAE 优先组 | **15.42** m³ CH4/d |
| MAE 对照组 | **40.11** m³ CH4/d |
| 相对降低 | **61.6%**（判据 ≥20% ✅） |
| 配对 bootstrap 95%CI | **[+15.28, +34.02]**（判据不含 0 ✅） |
| 有效组合占比 | 97%（判据 ≥80% ✅） |
| **判定** | **筛选有效** |

## 必须写进报告的边界

1. **这是模型内结论**，不是现场证据。全部为计算机仿真，未经实测检验。
2. **排序由范围选择决定。** `k_m_ac` 在标定包区间 [4,12] 下只有 −5%，在默认锚定区间 [3.9,35.3] 下是 **−74.7%**；`k_m_su` 在 [20,40] 下变化 0.00%，但压到 0.05 时产气从 1058 掉到 **189** m³/d。**范围若无文献依据，排序就不可信**——这是附录 B 必须逐项填依据的原因。
3. `k_m_su` / `k_m_h2` 在本次范围内为 0.000%，不等于"不重要"，而是**在该工况下处于饱和区（非限制步）**。
4. 尚未做：**2³ 全因子交互诊断**（计划书失败处理条款）、H2 工况迁移性、H3 端点法与 5 点扫描一致性。
